# מתח יומי 💪

אפליקציית טלפון קטנה וחמודה שמזכירה בעדינות לעשות מתח פעם ביום —
בשעה שנוחה לך, עם משפטים מעודדים לאורך הדרך. 💛

בנויה כ-**PWA** (אפליקציית ווב שאפשר להתקין על מסך הבית), עובדת יפה על אנדרואיד,
לא צריכה חנות אפליקציות, ולא שולחת שום מידע לשום מקום — הכול נשמר מקומית בטלפון.

## מה האפליקציה עושה

- ☀️ **בוקר טוב** — כל בוקר קבלת פנים חמודה ובקשה לבחור מתי נוח לך לעשות מתח היום.
- 🕒 **תזכורת** — בשעה שבחרת מגיעה התראה "הגיע הזמן למתח!".
- ✅ **אישור ביצוע** — כפתור "עשיתי!" עם קונפטי, ספירת רצף ימים (streak) ונקודות של השבוע.
- 💗 **משפטים מעודדים** — משפט חמוד ומתחלף בכל כניסה, וגם התראה מעודדת אחת במהלך היום.

## איך מפרסמים (חינם, דרך GitHub Pages)

1. היכנסו ל-repo ב-GitHub → **Settings** → **Pages**.
2. תחת **Source** בחרו **Deploy from a branch**.
3. בחרו את הענף שבו נמצא הקוד ותיקייה **/(root)**, ושמרו.
4. אחרי דקה-שתיים תופיע כתובת כמו:
   `https://<שם-המשתמש>.github.io/<שם-הrepo>/`
5. זהו — זו הכתובת של האפליקציה. 🎉

> חשוב: PWA עם התראות חייבת לרוץ תחת **HTTPS**. GitHub Pages נותן HTTPS אוטומטית, אז זה מסודר.

## איך היא (בת הזוג) מתקינה את זה על הטלפון (אנדרואיד)

1. לפתוח את הכתובת ב-**Chrome**.
2. ללחוץ על תפריט שלוש הנקודות → **הוספה למסך הבית / Install app**.
3. לפתוח את האפליקציה מהמסך הבית ולאשר את בקשת ההתראות.
4. בפעם הראשונה — לבחור שעה נוחה, וזהו. 💛

יש בתחתית המסך כפתור **"🔔 בדיקת התראה"** — כדאי ללחוץ עליו פעם אחת כדי לוודא
שההתראות מאושרות ומופיעות יפה.

## על ההתראות — מה חשוב לדעת

ההתראות (בוקר טוב / תזכורת / עידוד) נשלחות מהמכשיר עצמו כשהאפליקציה פתוחה או ברקע.
כדי שהתזכורות יהיו הכי אמינות, כדאי:

- **לא לסגור** את האפליקציה לגמרי (להשאיר אותה ברקע).
- לאשר לאפליקציה התראות בהגדרות הטלפון, ואם צריך — לבטל אופטימיזציית סוללה עבורה.

זו גרסה ראשונה ללא שרת. **הצעד הבא** (אם רוצים תזכורת מובטחת גם כשהאפליקציה סגורה
לגמרי) הוא להוסיף שרת Push קטן עם Web Push — אפשר להוסיף בהמשך בלי לשנות את העיצוב.

## איך משנים את הטקסטים המתוקים

כל המשפטים נמצאים בראש הקובץ [`app.js`](./app.js), במערכים:

- `MORNING_GREETINGS` — ברכות הבוקר.
- `ENCOURAGEMENTS` — משפטי העידוד.
- `DONE_LINES` — משפטי אחרי שעשתה מתח.

אפשר להוסיף/לשנות משפטים חופשי — פשוט לערוך את הטקסט בין הגרשיים ולשמור. 💌

## קבצים בפרויקט

| קובץ | תיאור |
|------|-------|
| `index.html` | מבנה האפליקציה |
| `styles.css` | העיצוב (הצבעים הרכים, האנימציות) |
| `app.js` | כל הלוגיקה + הטקסטים |
| `sw.js` | Service Worker (עבודה אופליין + התראות) |
| `manifest.json` | הגדרות ה-PWA (שם, אייקונים) |
| `icons/` | האייקונים של האפליקציה |
| `scripts/gen-icons.mjs` | סקריפט שמייצר את האייקונים מ-`icon.svg` |
| `scripts/test-app.mjs` | בדיקה אוטומטית של כל המסכים |

## פיתוח מקומי

```bash
# להריץ שרת מקומי פשוט
python3 -m http.server 8080
# ואז לפתוח http://localhost:8080

# לייצר מחדש אייקונים אחרי שינוי icon.svg (דורש node + playwright)
node scripts/gen-icons.mjs
```
