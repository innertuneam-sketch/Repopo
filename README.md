# מתח יומי 💪

אפליקציית אנדרואיד קטנה וחמודה שמזכירה בעדינות לעשות מתח פעם ביום —
בשעה שנוחה לך, עם משפטים מעודדים לאורך הדרך. 💛

זו **אפליקציה אמיתית** (קובץ `.apk`) שמתקינים כמו כל אפליקציה אחרת, עם אייקון משלה,
בלי דפדפן מסביב. היא לא שולחת שום מידע לשום מקום — הכול נשמר מקומית בטלפון.

## מה האפליקציה עושה

- ☀️ **בוקר טוב** — כל בוקר התראה חמודה שמזמינה לבחור מתי נוח לעשות מתח היום.
- 🕒 **תזכורת** — בשעה שנבחרה מגיעה התראה "הגיע הזמן למתח!" (עובד גם כשהאפליקציה סגורה).
- ✅ **אישור ביצוע** — כפתור "עשיתי!" עם קונפטי, ספירת רצף ימים (streak) ונקודות של השבוע.
- 💗 **משפטים מעודדים** — משפט מתחלף בכל כניסה, וגם התראת עידוד יומית.

---

## איך משיגים את קובץ ה-APK (בנייה אוטומטית ב-GitHub)

הקוד לא נבנה במחשב שלך — **GitHub בונה את האפליקציה בשבילך אוטומטית**:

1. אחרי כל דחיפה של קוד, נכנס תהליך בנייה (Workflow) בשם **"בניית אפליקציית אנדרואיד (APK)"**.
   אפשר לראות אותו בלשונית **Actions** ב-repo.
2. כשהבנייה מסתיימת (בערך 3–5 דקות), הקובץ מתפרסם בעמוד ה-**Releases** של ה-repo,
   תחת שם `מתח יומי — האפליקציה להורדה`.
3. הקישור הישיר להורדה:
   `https://github.com/innertuneam-sketch/repopo/releases/latest`

> אם לשונית **Actions** מבקשת להפעיל את ה-Workflows בפעם הראשונה — צריך ללחוץ פעם אחת
> על הכפתור הירוק כדי לאשר. אחרי זה הכול אוטומטי.

## איך מתקינים על הטלפון (אנדרואיד)

1. לפתוח בטלפון את קישור ה-`releases/latest` שלמעלה, ולהוריד את הקובץ `mtach-yomi.apk`.
2. ללחוץ על הקובץ שהורד. אנדרואיד יבקש אישור **"התקנה ממקורות לא ידועים"** — לאשר (חד-פעמי).
3. לפתוח את האפליקציה, לאשר את בקשת ההתראות, ולבחור שעה נוחה. וזהו! 💛

> זו אפליקציה חתומה בחתימת debug (מספיק בול להתקנה אישית). אין צורך בחשבון מפתחים
> או ב-Google Play.

## איך משנים את הטקסטים המתוקים

כל המשפטים נמצאים בראש הקובץ [`app.js`](./app.js), במערכים:

- `MORNING_GREETINGS` — ברכות הבוקר.
- `ENCOURAGEMENTS` — משפטי העידוד.
- `DONE_LINES` — משפטים אחרי שעשתה מתח.

עורכים את הטקסט בין הגרשיים, שומרים, ודוחפים — ו-GitHub יבנה APK מעודכן אוטומטית. 💌

## שינוי שם / אייקון / צבעים

- **שם האפליקציה**: השדה `appName` ב-[`capacitor.config.json`](./capacitor.config.json).
- **אייקון**: מחליפים את [`icons/icon.svg`](./icons/icon.svg) ומריצים
  `node scripts/gen-android-icons.mjs` (וגם `node scripts/gen-icons.mjs` לגרסת הווב).
- **צבעים ועיצוב**: הקובץ [`styles.css`](./styles.css).

---

## בונוס: גם גרסת דפדפן (PWA)

קבצי הליבה (`index.html`, `styles.css`, `app.js`) עובדים גם כאתר רגיל.
אפשר לפרסם אותם ב-**GitHub Pages** (Settings → Pages → Deploy from a branch → root)
ולקבל כתובת שנפתחת בכל טלפון. בגרסת הדפדפן ההתראות פחות אמינות כשהאפליקציה סגורה —
לכן אפליקציית ה-APK עדיפה לתזכורת יומית.

## מבנה הפרויקט

| קובץ / תיקייה | תיאור |
|------|-------|
| `index.html`, `styles.css`, `app.js` | האפליקציה עצמה (משותפת ל-APK ולווב) |
| `sw.js`, `manifest.json` | תמיכת PWA לגרסת הדפדפן |
| `capacitor.config.json` | הגדרות אפליקציית אנדרואיד (שם, מזהה) |
| `android/` | פרויקט האנדרואיד הנייטיב |
| `icons/` | אייקוני האפליקציה |
| `.github/workflows/build-apk.yml` | הבנייה האוטומטית של ה-APK ב-GitHub |
| `scripts/` | סקריפטים לייצור אייקונים ובדיקות |

## פיתוח מקומי

```bash
npm install
node scripts/build-www.mjs      # מרכיב את www/ עבור Capacitor
npx cap sync android            # מסנכרן לפרויקט האנדרואיד

# גרסת דפדפן מהירה לבדיקה
python3 -m http.server 8080     # ואז http://localhost:8080
```
